# 🎓 GPA Calculator

A simple web app to calculate your GPA from your modules, credits and grades.

**Live demo:** https://amaya514.github.io/gpa-calculator/

## Features
- Add or remove modules with credits and a letter grade
- GPA updates instantly on a 4.0 scale
- Shows your class (First Class, Second Upper, etc.)
- Saves your modules in the browser, so they're still there next time

## Built with
HTML, CSS and plain JavaScript. No libraries.

## Run it locally
Download the repo and open `index.html` in any browser.

## Note
The grade scale and class boundaries are a common 4.0 scale. Check your own university's handbook, and edit the `SCALE` values in `index.html` if yours is different.
